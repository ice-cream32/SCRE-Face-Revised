# 复现范围与实验协议

| 层次 | 本包支持情况 | 入口 |
|---|---|---|
| 冻结S01对420张图像推理 | 包含权重与可运行入口，须运行核验 | scripts/predict.py |
| 预测文件逐行比较 | 不读取测试真值、不改写标签 | scripts/verify_prediction.py |
| 内部流程指标复算 | 从保存的折外决策复算，不冒充新推理 | scripts/recompute_metrics.py |
| 历史0.37网格搜索 | 保存160张原图八视图评分，复算99候选 | scripts/replay_threshold.py |
| 全模型从零重训及全部消融重新训练 | 历史快照有工作区依赖，本包未提供完整独立训练入口 | archive/README.md |

先按原图划分FIT、ES、META、SEL、OUT，再生成退化视图；同一配对内角色互斥。第一阶段原图内容和常规增强，第二阶段继续相应权重，以一个常规视图和两个独立退化视图的BCE等权训练。DenseNet采用ImageNet监督预训练，冻结前缀与norm5，仅训练block4及分类头，BN运行统计固定。R/H使用GroupNorm。

ES用原图或固定16视图加权BCE选检查点；META拟合3个非负logit融合系数及截距；SEL独立选择救援阈值。原图权重0.5，其余15种各1/30。四压力视图仅作当轮评价。当前初判阈值0.37来自历史640/160、八视图开发搜索，未对最终级联联合重搜；它不是所有当前权重的全局最优保证。

内部原图790/800、标准加权98.0833%、压力均值97.6875%；平台0.964由用户报告，测试集无标签，本包不能本地复算测试准确率。项目多轮参考平台成绩和困难图反馈，平台成绩不应包装为一次性未触碰盲测。消融复用匹配权重，并区分固定删除F与重新校准R；不是所有架构均从零重训的必要性证明。
