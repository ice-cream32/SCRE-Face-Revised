# 初判阈值0.37的来源

历史训练集分层640/160（random_state=20261112；拟合两类各320，验证各80）。七网络家族概率平均：ResNet8三种子、HiRes19三种子、DenseNet121一个。验证八视图：原图、高斯σ1/1.5/2、降采样12/7、水平运动5、对比度0.3。原图权重1/2，退化各1/14。

逐一扫描0.01至0.99，步长0.01，共99点；最大化加权准确率（比较时保留12位小数），同分选距0.5近、再选小阈值。0.37为该配方99点中唯一最高值，99.7321428571%；0.36与0.38均99.6875%，0.50为99.4196428571%。在0.37处八视图错误数为0、0、1、4、0、1、0、0。160原图产生1280视图，不是1280独立样本。

训练#778非人脸高斯σ2评分0.36514946818，从阈值0.36到0.37修正误报；#362人脸评分0.37599873543，阈值0.38会新增漏检。产生同一分类的阈值区间约(0.36514946818,0.37599873543]；网格只包含其中0.37。

最终记录比较100配方，每配方先搜99阈值，再按加权准确率、最差视图准确率、加权BCE、网络数、名字排序。对照曾于首次训练后、首次预测前补齐，不能称100配方全部预注册。160张验证原图也参与检查点与配方选择，因此是开发成绩。当前模型继承0.37，未为完整级联重新联合寻优。
